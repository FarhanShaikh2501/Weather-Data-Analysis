
# Weather Data Analysis

## Overview
This project analyzes weather data using Python to identify patterns and trends.

## Libraries Used
- NumPy
- Pandas
- Matplotlib

## Analysis
- Data inspection and cleaning
- Statistical analysis
- Monthly temperature trends
- Humidity analysis
- Wind speed distribution
- Hourly temperature analysis
- Correlation analysis

## Dataset
The dataset contains weather observations, including temperature, humidity, wind speed, visibility, pressure, and weather conditions.

## How to Run
Install the required libraries:

```bash
pip install numpy pandas matplotlib
```

Open `main.ipynb` in VS Code and run the notebook cells.
